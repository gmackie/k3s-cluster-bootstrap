⏺ CPX11 Limitations:

  1. CI/CD Performance: Only 1-2 concurrent builds
  2. Shared CPU: May slow during peak times
  3. 2GB RAM: Need swap file for larger builds
  4. Better for: <10 developers, lighter workloads

  My Recommendation:

  Start with CPX11 if:
  - Budget is critical ($4 vs $6/month)
  - Small team (1-5 developers)
  - Simple CI jobs (no heavy builds)
  - Can upgrade later

  Go with CX21 if:
  - Need reliable CI performance
  - Running Docker builds
  - Multiple concurrent jobs
  - Team of 5+ developers

  Easy Upgrade Path:

  # Start with CPX11
  hcloud server create --type cpx11 --name gitea-ci

  # Later upgrade to CX21
  hcloud server poweroff gitea-ci
  hcloud server change-type gitea-ci --type cx21
  hcloud server poweron gitea-ci

  The CPX11 will work, just with performance constraints. You can always upgrade without losing data.
